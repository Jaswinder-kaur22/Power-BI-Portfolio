# Pizza Sales Performance Analysis | Power BI

## Project Overview

An interactive Power BI dashboard developed to analyze pizza sales performance,
revenue trends, customer ordering patterns, and product performance.

The project covers data cleaning and preparation, data modelling, KPI analysis,
and interactive data visualization.

## Business Objectives

- Evaluate overall revenue and sales performance
- Analyze monthly revenue trends
- Compare revenue across pizza categories
- Identify peak ordering hours
- Identify the best-selling pizza products

## Data Preparation

The raw dataset was cleaned and prepared before dashboard development, including:

- Reviewing and correcting data types
- Standardizing relevant fields
- Preparing data for analysis and modelling
- Ensuring consistency across sales-related variables

## Key KPIs

| KPI | Value |
| Total Revenue | $818K |
| Total Orders | 21K |
| Total Pizzas Sold | 50K |
| Average Order Value | $38 |

## Analysis

### Revenue Trend
Analyzed monthly revenue to identify changes in sales performance throughout
the year.

### Revenue by Category
Compared revenue across Classic, Supreme, Chicken, and Veggie pizza categories.

### Orders by Hour
Analyzed hourly order volumes to identify peak customer ordering periods.

### Top 5 Best-Selling Pizzas
Identified the five pizzas with the highest quantity sold.

### Interactive Dashboard
Users can filter the analysis by:

- Pizza category
- Pizza size
- Order date
